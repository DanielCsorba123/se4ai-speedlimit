We built REQ1 as specified, with three safeguards and an honest flag

Never “faster is safer”

A guard makes sure a lower limit is never rated riskier than a higher one.

Always reduce

In the dark or on ice the system chooses 70 km/h or lower, never 80.

No false precision

If no limit meets the target, take the highest one within 0.05/h of the best.

Target not reachable is shown to the operator with the predicted rate, instead of being hidden.

SpeedLimit MVP · 7 · Decisions D7, D8, D9, D25, D33

We did not change the requirement; we built it as written and protected it. A guard stops the model from recommending higher speeds because of that confounded history. When REQ1 is active the system always reduces. And when no limit reaches the target, it does not buy a meaningless improvement with twenty kilometres per hour. Above all, the operator sees when the target is out of reach.
