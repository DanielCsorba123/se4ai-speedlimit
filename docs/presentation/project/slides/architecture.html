The system is a router. Rules that the specification defines exactly, like what counts as dark, stay as plain code. The neural network only answers how much to reduce at night or on ice. The language model only handles air quality, and a fixed table takes over if it fails. In the end the strictest of the reasons sets the limit, and every decision is logged.
