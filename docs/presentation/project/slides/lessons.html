If we did this again, we would plot the target against the data on the first day, because that single chart reshaped the whole project. Domain rules like “slower is never riskier” have to be enforced in code; hoping the model learns them failed every time. Anything that depends on an external AI needs a fixed fallback. And AI-assisted coding works well when plans and tests come first: even our own early claim about a duplicated data line was caught by a test.
